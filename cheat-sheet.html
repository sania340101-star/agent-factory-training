Agent Factory — Шпаргалка ведущего

Иди последовательно: слайд за слайдом. Нажми номер → откроется нужный слайд.

Часть 1: Теория (~30 мин)
1
Титульный слайд
~1 мин
Поприветствовать. "Сегодня я расскажу как создавать AI-агентов, которые автоматизируют ваши задачи. Всё управляется через Telegram, голосом."
2
Что такое Agent Factory
~3 мин
Объяснить концепцию: Вы описываете задачу → Alex (Lead Agent) создаёт агента → агент работает 24/7. Примеры: парсинг сайтов, уведомления из CRM, отчёты, мониторинг. Всё через Telegram — не нужно ничего устанавливать.
3
Голосовой подход (КЛЮЧЕВОЕ!)
~5 мин
Это главный секрет платформы. Не нужно печатать длинные тексты. Просто запишите голосовое сообщение с вашими мыслями — даже сырыми, неструктурированными. Alex расшифрует (Whisper AI), структурирует и предложит план. Голосом в 5-10 раз быстрее, чем текстом.
Совет: запишите голосовое ПРЯМО СЕЙЧАС на обучении. Покажите как Alex структурирует сырые мысли — это впечатляет.
4
Workflow (инфографика)
~3 мин
Показать весь путь: Голосовое → расшифровка → структурирование → подтверждение → визард создаёт проект → агент работает → результат в Telegram. Всего 5 минут от идеи до работающего агента.
5
Чат (💬) vs Проект (🤖)
~3 мин
Два типа топиков. Чат — для обсуждений, мозговых штурмов, вопросов. Нет автоматизации. Проект — агент с кодом, расписанием, автоматизацией. Чат можно превратить в проект — просто напишите "создай проект" в чате. Это удобно: сначала обсудили идею, потом одной командой создали агента.
6
Создание проекта (визард)
~4 мин
Пошагово: Пишете "создай проект" → Alex спрашивает что нужно → вы описываете задачу (голосом!) → Alex предлагает интеграции и расписание → подтверждаете → проект создан, появляется новый топик 🤖. Весь процесс 2-5 минут. Также есть готовые шаблоны ("шаблоны") для типовых задач.
7
Память — 3 уровня (инфографика)
~5 мин
Важная тема — 3 уровня памяти.
1. Проектная (📁) — знания только для этого проекта. Сохраняется автоматически.
2. Юзерская (👤) — ваши предпочтения, знания между проектами. Все ваши проекты видят.
3. Общая (🌐) — для всей команды. Все видят.
Чем больше сохраняете — тем умнее становятся ваши агенты.
8
Как управлять памятью
~3 мин
Простые команды:
• "Сохрани в памяти" — сохранит в проектную или юзерскую (по контексту)
• "Сохрани для всех" — в общую память (все увидят)
• "Вспомни что мы обсуждали" — поиск по памяти
• "Структурируй мои мысли" — из хаоса → чёткий план
Подчеркнуть: говорите естественно, как человеку.
9
Основные команды
~3 мин
Пройтись по ключевым: создай проект, статус, расходы, включи/выключи, стоп, помощь, расписание, интеграции. Обратить внимание: все команды работают и на русском и на английском. "Помощь" — одно слово, покажет все команды. Не нужно запоминать — всегда можно спросить.
10
Модели AI
~2 мин
Три модели: Haiku (простые, дёшево) → Sonnet (средние) → Opus (сложные, дорого). Alex выбирает автоматически — юзеру не нужно думать. Чем проще задача — тем дешевле. Можно посмотреть расходы командой "расходы".
11
Расписание и триггеры
~3 мин
Три режима работы:
• По команде — вы пишете задачу, агент выполняет
• По расписанию — каждый день, каждую неделю
• По триггеру — событие в CRM (новый лид, заказ) → агент автоматически запускается
Настраивается при создании проекта.
12
Как Alex работает — субагенты
~3 мин
Alex — Lead Agent. Для сложных задач он привлекает субагентов:
• 📐 Planner — планирует архитектуру
• 💻 Developer — пишет код
• 🔍 Reviewer — проверяет качество
• 🔌 Integrator — подключает сервисы
Юзер общается ТОЛЬКО с Alex'ом. Субагенты могут работать параллельно — это ускоряет. Показать на примере: "Alex создаёт проект → planner составляет план → developer пишет код → reviewer проверяет."
13
Архитектура (инфографика)
~2 мин
Обзорно: Показать как устроена система — Telegram → Router → Claude AI → MCP серверы (Odoo, Obsidian). Не углубляться в техдетали. Главное — всё работает автоматически, юзеру не нужно знать что внутри.
14
Надёжность: self-healing, бэкапы, изоляция
~2 мин
Три уровня надёжности:
• Self-Healing — если агент упал, Alex автоматически диагностирует и предложит фикс
• Бэкапы — ежедневные автоматические. Удалённые проекты → корзина, можно восстановить
• Изоляция — каждый юзер видит только свои данные, чужие проекты недоступны
Часть 2: Live Demo (~20 мин)
15
Практика: создаём агента вживую
~20 мин
Показать на реальном примере от начала до конца:
1. Создать новый топик в группе → появляется 💬 чат
2. Записать голосовое: "Хочу чтобы каждое утро приходила сводка новых лидов из CRM с именем, компанией, телефоном"
3. Alex расшифрует и ответит. Сказать: "Структурируй и предложи план"
4. Alex выдаст план. Подтвердить.
5. "Создай проект" → визард → подтвердить
6. Показать: "статус" → видим агента
7. Показать: "расходы" → видим стоимость
8. В топике проекта: "Сохрани в памяти: отчёт всегда в формате таблицы"
9. Показать: "выключи {name}" → "включи {name}"
Совет: делайте паузы, пусть участники повторяют у себя в группе параллельно.
16
Скиллы — 300+ готовых
~3 мин
Объяснить экосистему скиллов: Скилл — это набор инструкций для агента. 300+ готовых: маркетинг (cold-email, SEO, copywriting), C-level (CEO, CFO, CMO advisor), продуктовые (product-manager, PRD), финансы. Можно создать свой скилл и опубликовать для команды.
Показать: "скиллы" → список.
В Web UI: Skills → Built-in → поиск "marketing" → раскрыть описание.
"Создай скилл" → визард проведёт по шагам.
17
Веб-интерфейс
~3 мин
Кроме Telegram есть веб-интерфейс: Dashboard с агентами и расходами, чаты (те же что в Telegram), скиллы с поиском по 300+ категориям, настройки. Вход по email + пароль. Удобно когда нужно посмотреть расходы, управлять скиллами, или работать с компьютера.
Открыть server:3380/user → показать dashboard, чаты, скиллы → поиск built-in → создать проект через UI.
Совет: Web UI и Telegram синхронизированы — всё что создано в одном видно в другом.
Часть 3: Q&A (~10 мин)
18
Вопросы и ответы
~10 мин
Частые вопросы:
• "Как остановить зависший агент?" → "стоп"
• "Сколько стоит?" → "расходы" (от $0.01 до $2 за задачу)
• "Можно по расписанию?" → Да, при создании проекта
• "Что если ошибка?" → Система самовосстановления
• "Как удалить?" → "удали {name}" → корзина → можно восстановить
