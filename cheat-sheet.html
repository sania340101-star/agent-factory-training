Теория: Что это и зачем
~30 мин
Что такое Agent Factory
Платформа для создания AI-агентов через Telegram. Описываешь задачу голосом — получаешь автоматизацию.
Открыть: Инфографика "Создание ИИ-агентов за 5 минут"
Голосовой подход (KEY!)
Главный паттерн: наговорить сырые мысли → Alex структурирует → план → проект. Голосом быстрее чем текстом в 5-10 раз.
Совет: покажите на своём примере — запишите голосовое прямо на обучении и покажите как Alex структурирует
Telegram: группы и топики
Группа = рабочее пространство. Топик = чат или проект. Каждый топик — отдельная задача.
Чат (💬) vs Проект (🤖)
Чат — обсуждение, мозговой штурм. Проект — агент с автоматизацией. Чат можно превратить в проект командой "создай проект".
3 уровня памяти
Проектная (только этот проект) → Юзерская (все ваши проекты) → Общая (все видят).
Открыть: Инфографика "3 уровня памяти"
Модели: haiku / sonnet / opus
Haiku = дёшево ($0.01-0.05), Sonnet = баланс ($0.05-0.30), Opus = мощно ($0.50-2.00). Alex выбирает автоматически.
Основные команды
статус, проекты, расходы, помощь, создай проект, включи/выключи, стоп, расписание
Открыть: Quick Start Guide (команды)
2
Как пользоваться
~20 мин
Создание проекта через визард
"создай проект" → Alex спрашивает задачу → предлагает интеграции → подтверждение → проект создан
Открыть: Инфографика "Голосовой workflow"
Шаблоны (опционально)
Есть готовые шаблоны ("шаблоны"), но основной способ — визард. Упомянуть кратко.
Расписание и триггеры
По расписанию: "каждый день в 9:00". По триггеру: "когда новый лид в CRM".
Работа с памятью
"Сохрани в памяти" → проектная/юзерская. "Сохрани для всех" → общая. "Вспомни" → поиск.
Управление агентами
Включить/выключить, переименовать, удалить, корзина, восстановить. Статус, расходы, метрики.
Совместная работа
Запрос доступа к чужому проекту. Общая память для команды.

Live Demo
~20 мин
1. Создать чат-топик
Создать новый топик в группе → 💬 чат создаётся автоматически
2. Наговорить идею голосом
Записать голосовое: "Хочу чтобы каждое утро приходила сводка..."
3. "Структурируй мои мысли"
Alex выдаёт чёткий план
4. "Создай проект"
Визард → подтверждение → топик 🤖 создан
5. Посмотреть результат
"статус" → "расходы" → "метрики"
6. Сохранить в память
"Сохрани в памяти: формат отчётов — всегда таблицей"
7. Включить/выключить
"выключи {name}" → "включи {name}"
