Что такое Agent Factory?

Платформа для создания AI-агентов, которые автоматизируют ваши задачи.

  • Общаетесь с Alex через Telegram
  • Описываете задачу голосом
  • Alex создаёт агента
  • Агент работает за вас 24/7
🎤

Главный секрет: говорите голосом!

Ваши мысли быстрее, чем вы печатаете.
Наговорите сырые идеи — Alex структурирует за вас.

"Мне нужно чтобы каждый день приходила сводка лидов из CRM... Структурируй мои мысли и предложи план."

Как это работает

💬 Чат vs 🤖 Проект

💬 Чат

Обсуждения, мозговые штурмы, вопросы. Нет автоматизации. Создаётся при новом топике.

🤖 Проект

Агент с автоматизацией. Работает по команде, расписанию или триггеру. Создаётся через визард.

Чат → Проект: напишите "создай проект" прямо в чате

Создание проекта

  • Напишите или скажите: "создай проект"
  • Alex спросит: что должен делать агент?
  • Опишите задачу голосом — Alex структурирует
  • Alex предложит интеграции и расписание
  • Подтвердите план — проект создан!

Весь процесс — 2-5 минут

🧠 Память (3 уровня)

Как управлять памятью

"сохрани в памяти"
Проектная или юзерская
"сохрани для всех"
Общая (все увидят)
"вспомни что мы обсуждали"
Поиск по памяти
"структурируй мои мысли"
Из хаоса → план

Чем больше сохраняете — тем умнее агенты!

⏰ Расписание и триггеры

  • По команде — вы пишете задачу, агент выполняет
  • По расписанию — каждый день в 9:00, каждый понедельник
  • По триггеру — новый лид в CRM → агент запускается

Расписание и триггеры настраиваются при создании проекта

💡 Советы

  • Голосом быстрее — записывайте голосовые сообщения
  • Сырые мысли → структура — скажите "структурируй"
  • Память = знания — чем больше сохраняете, тем умнее агент
  • Фото и файлы — отправляйте прямо в чат
  • "Помощь" — забыли команду? Одно слово.
