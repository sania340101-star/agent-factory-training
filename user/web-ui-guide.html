🔑 Вход в систему

Email + пароль

Получите учётные данные у администратора. Откройте server:3380/user в браузере и войдите с email и паролем.

Первый вход

После первого входа рекомендуется сменить пароль в разделе Настройки.

🔀 Таблица агентов

Список всех ваших агентов. Для каждого: имя, статус, последний запуск, расход. Кнопки ON/OFF для управления и удаление (проект уходит в корзину).

💬 Чаты

Все ваши диалоги с агентами в одном месте.

➕ Создание нового чата

Нажмите "Новый чат" — выберите тип из dropdown:

💬 Chat
Свободный диалог
🤖 Project
Агент + wizard
⚡ Skill
Навык + wizard

Для типов Project и Skill автоматически запускается wizard — он проведёт вас через настройку шаг за шагом.

🔍
Поиск
Быстрый поиск по названию чата
🗑️
Удаление
Удалённые чаты уходят в корзину

⚡ Скиллы

Готовые навыки для агентов. Более 300 встроенных скиллов на все случаи.

👤 Personal

Ваши скиллы

🌐 Shared

Общие (от админа)

📦 Built-in

300+ готовых

🔍 Поиск и категории

Ищите скиллы по названию или фильтруйте по категории:

marketing c-level engineering product finance business-growth

Создание своего скилла

Напишите в чате создай скилл — wizard поможет описать навык, задать параметры и сохранить. Админ может поделиться скиллом (Shared) с другими пользователями.

📊 Таблица расходов

Каждая строка — запуск агента: дата, проект, модель (Haiku/Sonnet/Opus), стоимость. Сортировка по дате, фильтры по проекту и периоду.
